# 🚆 Railway Station Management System

## **📌 Project Overview**
The **Railway Station Management System** is a web application built using **PHP and MySQL**, following the **MVC architecture**. It is designed to manage railway station operations, allowing users to **view train schedules, book tickets, and manage their profiles**. The project uses **Composer for dependency management** and **PDO for secure database operations**.

### **✅ Key Features**
- 🔹 **User Authentication** (Register, Login, Logout)
- 🔹 **Train Schedule Management** (View train schedules)
- 🔹 **Ticket Booking System** (Search for trains and book tickets)
- 🔹 **Booking History** (View past and upcoming bookings)
- 🔹 **User Profile Management** (Update username and password)
- 🔹 **Session & Cookies for Authentication**
- 🔹 **Composer Autoloading & Namespaces**
- 🔹 **PDO-based Secure Database Operations**

## **📌 How to Run the Project**
### **🔹 1. Install Dependencies**
Make sure **PHP, MySQL, and Composer** are installed on your system.

Run the following command to install dependencies:
```sh
composer install
```

---

### **🔹 2. Set Up the Database**
1. Open MySQL and create the database:
   ```sql
   CREATE DATABASE railway_station;
   USE railway_station;
   ```
2. Create the required tables:
   ```sql
   CREATE TABLE users (
       id INT AUTO_INCREMENT PRIMARY KEY,
       username VARCHAR(50) NOT NULL UNIQUE,
       password VARCHAR(255) NOT NULL,
       created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
   );

   CREATE TABLE trains (
       id INT AUTO_INCREMENT PRIMARY KEY,
       train_name VARCHAR(100) NOT NULL,
       departure_time TIME NOT NULL,
       arrival_time TIME NOT NULL,
       route VARCHAR(255) NOT NULL
   );

   CREATE TABLE bookings (
       id INT AUTO_INCREMENT PRIMARY KEY,
       user_id INT NOT NULL,
       train_id INT NOT NULL,
       booking_date DATE NOT NULL,
       status ENUM('Confirmed', 'Cancelled') DEFAULT 'Confirmed',
       FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
       FOREIGN KEY (train_id) REFERENCES trains(id) ON DELETE CASCADE
   );
   ```

---

### **🔹 3. Configure Environment Variables**
Create a `.env` file inside the `config/` folder and add:
```
DB_HOST=localhost
DB_NAME=railway_station
DB_USER=Tommy
DB_PASS=12345
```


### **🔹 4. Run the Project**
Start the PHP built-in server:
```sh
php -S localhost:8000 -t public
```
Then, open your browser and visit:
```
http://localhost:8000
```
